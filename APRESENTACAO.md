# Apresentacao profissional

## Identidade e valor

Raizes e uma aplicacao com frontend Angular e backend Python voltada a visualizacao e comparacao de informacoes geograficas e ambientais. Os componentes de mapa, producao por cidade e comparacao entre estados indicam uma experiencia focada na leitura territorial dos dados.

## Texto para publicacao

> O Raizes foi concebido para tornar dados territoriais mais exploraveis por meio de uma interface cartografica e comparativa. A aplicacao separa um frontend Angular de um backend Python, ambos preparados para execucao em contenedores. O desafio foi estruturar uma navegacao que aproximasse visualizacao em mapa, recortes por cidade e comparacao entre estados. O projeto estabelece uma base para comunicar informacoes geograficas de forma mais acessivel, mantendo referencias de prototipo e de API para apoiar sua evolucao.

## Evidencias visuais recomendadas

1. Mapa principal com controles e marcadores.
2. Visualizacao de producao por cidade.
3. Comparacao entre estados.
4. Resposta documentada da API.
